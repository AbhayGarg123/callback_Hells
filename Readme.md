# JavaScript Promise Division

## 📌 Project Description

This project demonstrates how to perform division using a JavaScript **Promise** and an **Arrow Function**.

The function takes two numbers as input and returns a Promise. If the second number is `0`, the Promise is rejected with an appropriate error message. Otherwise, the Promise is resolved with the result of the division.

The project also demonstrates how to handle resolved and rejected Promises using `async/await`, `try...catch`, and multiple test cases.

## 🚀 Features

- Uses a JavaScript Arrow Function
- Returns a Promise
- Performs division of two numbers
- Handles division by zero
- Uses `resolve()` and `reject()`
- Handles errors using `try...catch`
- Uses `async/await`
- Includes 5 different test cases
- Displays the result/error along with each test case

## 🛠️ Technologies Used

- JavaScript
- Promises
- Async/Await
- Arrow Functions
